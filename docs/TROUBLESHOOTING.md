# 常见问题

## 页面无法打开

确认终端中的服务仍在运行，并访问 `http://localhost:8765`。如果端口被占用，请先关闭占用进程，或按项目配置修改端口。

## 模型调用失败

1. 检查 `.env` 是否存在，变量名是否与 `.env.example` 一致；
2. 检查密钥是否有效、账户是否有可用额度；
3. 检查当前网络能否访问所配置的 API；
4. 查看终端中的原始错误信息，不要把密钥粘贴到 Issue 或日志截图中。

## 公司速查没有结果

公司速查依赖公开网页。名称过短、同名公司、网页反爬或网络异常都可能影响结果。建议输入完整公司名称，并将结果作为求职调研线索而非最终事实。

## PDF / Word 导入不完整

复杂分栏、扫描件或特殊字体可能导致文本提取缺失。可先转换为可复制文本的 PDF / Word，导入后在经历管理中人工核对。

## 导出的简历超过一页

优先减少低相关经历与重复表述，再调整字号和间距。不要仅通过极小字号强行压缩，以免影响阅读。

## 如何保护个人信息

本地使用时不要提交 `.env`、个人简历、证件照和导出文件。向他人反馈问题前，请先删除电话、邮箱、住址、密钥等敏感信息。
