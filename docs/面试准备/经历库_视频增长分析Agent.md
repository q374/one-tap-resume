## 项目① one-tap-resume 智能简历定制工具

- **角色**：独立搭建
- **时间**：2026.07 - 至今
- **背景**：求职市场信息不对称——56.9%求职者不会挖掘自身亮点、54%用同一份简历海投、HR平均6秒筛一份简历、90%无回音源于匹配度不足。核心痛点：求职者为不同岗位反复改简历、经历写不出亮点。基于此从0到1设计并实现 AI 简历定制工具，主打"一次录入、按 JD 自动定制"。
- **动作**：
  - 需求与产品：独立完成需求调研、竞品分析、PRD 撰写（目标用户/核心场景/功能清单/验收指标），明确差异化定位
  - AI 能力落地：内置 12 大行业简历侧重点知识库（RAG），粘贴 JD 自动识别行业并注入生成提示词；设计 AI 质量诊断体系（六项检查：禁套话/要量化/篇幅/命中JD关键词/无占位符/真实性）
  - Agent 化功能矩阵：模拟面试（按岗位+简历定制出题、答完点评）、公司洞察/速查、AI 辅助修改（红绿区分增删）、投递记录、经历自动去重、自定义模板导入、一键适配单页 A4
  - 工程落地：FastAPI + SQLite + DeepSeek API + 原生前端全栈实现；同步开发 Skill 版上架 Astron SkillHub
- **结果**：开源至 GitHub 并上架 SkillHub；参加科大讯飞 AI 开发者大赛（1600 支队伍中热度 Top 25，约前 2%）；15 个不同背景测试用例验证生成质量稳定；生成一份定制简历约 15 秒、成本不到 5 分钱；一次录入终身复用，覆盖 12 大行业；形成"需求调研→PRD→技术验证→上线→参赛验证"完整产品闭环
- **技术栈**：Python/FastAPI/SQLite、DeepSeek API、RAG 知识库、Prompt Engineering、需求分析/PRD、竞品分析、用户调研、指标设计、Git/GitHub

## 项目② AI 视频制作全流程 Agent

- **角色**：独立搭建
- **时间**：2026.08 - 至今
- **背景**：为 one-tap-resume 做冷启动宣传，无广告预算、无粉丝基础，人工剪辑效率低。验证"AI Agent 能否替代内容生产的人力"，同时沉淀可复用内容方法论。
- **动作**：
  - Agent 流水线设计：接收目标（产出一条宣传视频）→ AI 自动写文案 → 自动配音 → 自动渲染成片 → 自动生成封面，几分钟产出一条，全程无需人工干预
  - 人在环（Human-in-the-loop）设计：AI 执行完成后由我发布前最终审核，质量过关才发布——用产品思维解决"AI 生成质量不稳定"
  - 数据驱动迭代：发布后导出抖音数据复盘，反推文案钩子/时长/标签策略，形成"生产→发布→数据→迭代"闭环
- **结果**：产出 33 条视频，3 条进入账号历史播放 Top3、单条破千；通过 A/B 迭代，5s 完播率提升 3.3 倍（10.8% → 35.7%）、2s 跳出率从 67.6% 降至 39.0%（对标行业优秀水平）；沉淀可复用方法论：数字钩子>口号、短视频>长视频、开头3秒高光前置、标题/封面/开头三处钩子统一；验证 AI Agent 可替代内容生产人力，同时证明"人工审核"是 AI 内容产品必要环节
- **技术栈**：Python、DeepSeek API、edge-tts 配音、Remotion/HyperFrames 程序化渲染、抖音数据分析、A/B 测试

## 项目③ AI 简历诊断工作流（Dify + RAG）

- **角色**：独立搭建
- **时间**：2026.07 - 至今
- **背景**：市面简历工具诊断空泛，无法针对具体岗位给出可执行改进建议。目标：用真实招聘 JD + 简历做 AI 质量诊断，覆盖 12 大行业。
- **动作**：
  - 工作流编排：用 Dify 搭建『开始（简历+JD）→ 知识检索（12大行业知识库）→ 条件分支 → 双LLM → 结束』完整流程
  - 诊断体系设计：六项检查——禁套话/要量化/控制篇幅/命中JD关键词/无占位符/真实性
  - 工程排坑：解决变量插入、输出节点配置、RAG 上下文接入等真实工程问题
- **结果**：工作流跑通，实测案例：对『AI产品经理实习生（AIGC方向）JD + 真实简历』输出六项诊断——禁套话88/要量化93/控制篇幅68/命中JD关键词70/无占位符100/真实性75，总分83；Top3 建议：①补全 JD 点名工具链（Coze/即梦/可灵/Midjourney/ComfyUI/Vibe Coding）②压缩至一页 A4 并把 AIGC 项目前置 ③修正夸大表述并补可核实口径（如"Top25 约前2%"、"替代人力→压缩80%工时"），每条附具体改后例句
- **技术栈**：Dify、DeepSeek API、RAG 知识库、Prompt Engineering、流程编排

## 项目④ 抖音视频增长分析 Agent（Dify）

- **角色**：独立搭建
- **时间**：2026.08 - 至今
- **背景**：账号冷启动期播放波动大（40~1252），内容决策靠经验判断。目标：把"数据→归因→决策"链路 Agent 化，验证 AI 能否替代人工数据分析师做增长决策。
- **动作**（四大能力落地）：
  - ①目标：系统提示词写死角色目标——从真实数据定位问题、验证假设、产出可执行方案
  - ②任务拆解：内置 5 步分析 SOP（取数→算指标→对比合格线→归因→给建议），模型自主规划执行顺序
  - ③工具调用：挂载知识检索（方法论+数据双 RAG 库）与 Python 代码执行（算环比/TOP/BadCase），由模型自主决策调用
  - ④记忆：Agent 多轮上下文，前轮结论自动带入下轮分析
  - 以 33 条真实视频 + 3 天账号汇总数据驱动
- **结果**：跑通输出完整归因报告，实测案例：让 Agent 回答"现在最该改的一个动作"，它给出"把开头 3 秒改成第 0 帧数字钩子、把 2s 跳出压到 45% 以下"，并用数据支撑——8-16 跳出 66%（超合格线 21 点）、播放≥600 的 5 条跳出均值仅 44%（全合格）vs 播放<150 的 5 条均值 61.9%（全超标）、爆款 43.7% vs 口号翻车 67.6%，结论"这是唯一改了就能见效的杠杆"；识别"权重惩罚 vs 内容恶化"矛盾信号、区分数据支撑与推断、剔除噪音、给带验收标准的建议；沉淀账号权重/流量池判断方法论与 5 步分析 SOP
- **技术栈**：Dify、DeepSeek API、RAG 知识库、Python(pandas)、Prompt Engineering、Agent（目标/工具调用/记忆/任务拆解）
