## 一、目标岗位

AI 产品经理 / AI 产品助理 实习。方向：AI 应用产品、Agent/工具类产品。

## 二、核心项目素材（按经历录入格式）

### 项目 A：AI 简历定制工具 one-tap-resume（独立开发 · 主项目）
- **定位**：解决求职者"反复改简历、岗位匹配差"痛点——一次录入个人经历，按岗位 JD 自动生成定制简历
- **技术**：Python + FastAPI + SQLite + DeepSeek API + 前端静态页；Skill 版（SKILL.md Agent 技能）
- **功能链（6 Tab）**：AI经历导入 → 经历管理(自动分类/去重) → 行业侧重点分析(内置12行业知识库) → 按JD生成定制简历 → 网页预览+AI辅助修改(红绿区分增删) → 一键适配一页A4 → AI质量诊断(禁套话/要量化/控篇幅/命中JD关键词等6项) → 模拟面试(按岗位+简历定制出题+逐题点评) → 公司洞察/速查 → 投递记录
- **量化成果**：一次录入、终身复用；15秒生成一份定制简历；单份成本不到5分钱（一杯蜜雪柠檬水≈130份）；读得懂12大行业潜规则；AI绝不编造（宁留白不造假）
- **运营/市场**：开源 GitHub（q374/one-tap-resume）；参加科大讯飞"人才匹配与发展智能辅助Skill开发挑战赛"（专家榜+热度榜双赛道）；SkillHub 可下载
- **工程实践**：经历库强约束提示词、AI解析健壮性(JSON raw_decode)、测试隔离(禁污染真实库)、安全修复(文件读取漏洞/CORS收紧/依赖瘦身)

### 项目 B：AI 工具视频增长（抖音宣传 · 数据驱动迭代）
- **定位**：用做 AI 产品同样的思路做冷启动增长——用 Agent 流水线(Codex/Claude 双线)自动化生产宣传视频
- **技术**：Remotion/HyperFrames 程序化渲染 + edge-tts 配音 + 豆包生图 + 数据复盘
- **数据驱动闭环**：发布后导出抖音数据 → 看 2s跳出率/5s完播率/完播率 → 反推文案钩子和时长 → 下一期改
- **关键迭代（A/B 实证）**：
  - 120s长片「刷到我」→ 播放40 / 完播0% → 结论：冷启动不投长片
  - 15s「简历只写一次」→ 播放626 / 2s跳出53.9%
  - 「HR筛简历只要6秒」数字钩子 → 播放680 / 5s完播35.7%（历史最佳完播）
  - 破千播放三条（1252/1249/1216）5s完播25.6%-31.5%
  - 003(28s) 播放302 / 2s跳出55.19% → 结论：痛点陈述+长时长双输 → 004(15s 数字钩子) 重做待验证
- **沉淀规律**：数字反常识 > 口号/痛点陈述；开头3秒高光前置；钩子三处统一(标题=封面=开头)；指标线(2s跳出≤45%/5s完播≥25%)

## 三、面试答题框架（讲项目必背）

1. **痛点从哪来**：网络调研/常识判断——求职者改简历是最大痛点；HR 筛简历平均仅 6 秒；信息不对称(简历与岗位不匹配)
2. **产品决策**（为什么这么做）：
   - 选 DeepSeek API 不自建模型 = 轻资产快验证
   - 12 行业知识库内置 = 零成本"行业侧重"能力，不接外部平台
   - 模板先做黑白简约 2 款 = 快速验证核心链路
   - 成本控制 = 每份 <5 分钱，可规模化
3. **数据反馈驱动迭代**（把视频增长当产品实验）：
   - 2s跳出 55% → 改开头钩子
   - 文案/封面/时长 A/B → 沉淀规律进规则库
   - 用户反馈（一页A4/预览导出一致/边距）→ 快速修
4. **差异化/壁垒**：真实经历绝不编造、自动去重、行业侧重点、一次录入终身复用
